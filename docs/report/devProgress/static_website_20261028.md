# 静态网站首版实施（2026-10-28）

## 完成范围

对应 [网站规划](../../Proposal/static_website_plan.md) 的 A 阶段及 B 阶段本地内容/数据基础。
工程为 `website/`，独立于桌面 CMake、用户安装目录、Core/SDK 和插件运行时。
使用 Astro 7.4.2 静态输出、Markdown 内容与构建期 Zod schema，不含服务器端运行服务、数据库或访客跟踪脚本。
模板替换入口为 layouts/components/styles；内容、数据、路径独立维护。

- 首页、下载、插件列表/详情、教程、版本历史、开发者、关于、公告、404，共 21 个 HTML 页面。
- 插件页支持浏览器本地关键词/发布者类别筛选；无 JavaScript 时完整列表与导航仍在 HTML 中。
- 四个插件版本及最低 Core 范围与源码 manifest 核对；八篇使用教程包含常见的缺引擎/按钮缺失说明。
- 下载信息使用结构化资产记录，支持名称、固定 URL、大小、SHA-256、内容和配置要求；网页与目录生成共用数据。
- 校验重复 ID、SemVer、日期、兼容范围、资产字段、文章对应关系和官方 catalog 变体限制。
- stable/prerelease 不允许空资产或明显指向 main/master/latest 的可变来源/资产路径。
- `catalog:preview` 仅输出 `.astro/catalog-preview/plugins-v1.json`，不输出公共目录路由。
- 包锁定在 package-lock；Node 24+。构建/预览关闭 Astro 遥测，不写全局遥测配置。
- `website/README.md` 包含安装、构建、子路径部署、内容维护及发行门禁说明。

当前没有导入经核实的正式发行资产：下载页显示待开放，版本历史为空，四个插件显示开发中。
没有把本地包地址、源码版本或测试报告包装成稳定发行；首页为明确标注的交互示意，尚无实际产品截图。

## 验证

环境：Windows、Node 24.19.0、npm 11.17.0。仅网站改动，不运行桌面完整测试套件。

| 检查 | 结果 |
| --- | --- |
| `npm test` | 10/10 通过，覆盖无效数据、重复、变体/第三方/撤回 catalog 拒绝及输出字段 |
| `npm run build`，根路径 | 21 HTML、323 处本地引用通过，总产物 59,838 字节（约 58.4 KiB，未压缩） |
| `WEBSITE_BASE=/Nskry/` 构建 | 21 HTML、323 处本地引用通过；最终 dist 已恢复根路径构建 |
| `npm run catalog:preview` | schema 1 空开发预览成功；未进入 dist，未配置客户端 |
| npm 安装审计 | 初始 Zod 3 版本存在高风险公告；升级 4.6.7 后安装审计报告 0 漏洞 |
| 本地浏览器 | 首页布局、插件导航、搜索“翻译”返回一个条目、翻译教程内容检查通过 |
| 390×844 视口 | 插件列表单列、筛选控件和卡片可用；恢复默认视口 |
| `git diff --check` | 通过；已跟踪历史文件有 LF→CRLF 提示，无空白错误 |

无发布记录导致 Astro 对空 releases 集合给出提示；这是当前无公开资产的预期状态，构建成功。
禁用 JS 可用性来自生成 HTML/渐进增强结构核对，未声称完成浏览器禁用 JS 的独立操作验收。
尚未做全站人工键盘/屏幕阅读器验收，已提供 skip link、语义导航、表单标签、焦点样式和响应式布局。
产物大小不是浏览器峰值内存或总网络传输测量。
