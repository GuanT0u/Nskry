- 明确允许合规 fork 销售和收费安装服务，要求真实说明 Nskry 来源、保留许可与版权、不冒充官方。

## 桌面框选

根因：SelectionWindow::OnLButtonDown 要求 m_targetHwnd 非空，而 WindowEnumerator 明确不把桌面作为可吸附应用。
修复：开始拖动不再要求窗口目标；按下时刷新吸附目标，离开窗口时清空旧 bounds；
松开时纳入最后坐标，空白单击保持未选择，不把桌面伪装为 WGC 窗口。
应用窗口点击吸附保留。未扩大 PiP 的可捕获来源范围。

回归测试在隐藏测试窗口内注入确定的空目标/模拟吸附列表，不发送真实鼠标输入给其他进程，不保存桌面图像。
覆盖：桌面开始拖动、反向拖动、松开终点、空白单击、无先行鼠标移动的应用吸附、旧目标清除。
