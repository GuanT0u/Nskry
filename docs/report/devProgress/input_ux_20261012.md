# 快捷键、框选与切除体验优化

日期：2026-10-12。本轮实现，不提交/推送，不安装用户插件，不强制停止用户程序。

同日后续复审已纠正来源分区、元数据重复与配置保留等问题，当前状态见
[代码审查报告](code_review_20261012.md)；下文保留此次首次实现的验证记录。

## 对应十项要求

1. 自有快捷键统一目录：全局截图/退出/监控，选区复制/保存/取消，标注撤销/重做，
   文字确认/取消，编辑器确认/取消，精调键，滚轮缩放/两轴平移；OCR 提供其局部输入描述符。
2. 默认纯显示，Record / Type / Delete。Record 展示完整按键集合，在全部抬起时结束；
   Type 才打开输入框，Delete 禁用。录制期间暂停 Nskry 全局键，失焦/离页/关闭恢复。
3. Core、官方产品 profile、第三方分区，插件名作子标题；General 跳转入口同样分组。
   Profile 不是对本地包的发布者认证，Plugins 页原有来源警告不变。
4. 监控/OCR/Scroll 全局入口默认空，未安装插件也有 launch 预留行；调用缺包/禁用功能会提示。
5. general_jump 元数据决定跳转入口，非“为空才显示”；定位目标行给予两次浅色对比提示，
   约 880 ms 后停止临时定时器。
6. 快捷入口框选松开后直接进入监控/OCR/滚动操作；普通截图保留调整与工具栏。
   桌面无实时来源窗口时，监控明确要求选取窗口内部区域。
7. Input appearance：桌面框选实线/虚线、1–6 px、0–100% 透明度、预设/自定义颜色。
   裁剪参考线、OCR highlight、Scroll 提示边框保留自身语义，不宣称全部渲染层被统一覆盖。
8. Cut 默认红色半透明，可选遮罩+网格、仅切线、旧网格风格，可调颜色/透明度与同时显示边框。
   Rows 仅上下切线，Columns 仅左右切线；预览样式不进入输出像素。
9. 五种状态（框选、选区移动、行切除、列切除、图像平移）可选择系统形状或 .cur/.ani，
   失效文件回退指针；外观可重置。动画由系统处理，其成本未做实机基准。
10. Cut 光标仅在截图与可见画布交集内出现；OCR 选区用选择光标；点击画布设置焦点，
    避免精调键触发之前选中的按钮。

## 资源与未来边界

- 只创建可见快捷键行及少量缓冲行的控件，滚动保留数据、释放离屏控件。
- 没有新常驻键盘 hook/轮询；局部组合解析缓存，自定义光标按状态缓存，不在每次移动读取文件。
- 全局绑定允许交换、删除，失败回滚；设置 flush 后原子替换，避免半份文件。
  未知/未来 command id 保留，不削掉预留接口或改 API 2 ABI。
- 本轮输入扩展独立版本化；元数据发现不加载 DLL，Apply 只更新已加载插件。
- OCR 推理、滚动算法、监控帧率、许可例外、前置插件规划保持不变。
