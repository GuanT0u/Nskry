# Nskry 桌面 UI 设计规范与实施计划

2026-11-23 · 设计基线 v1。本文件描述改版目标和验收条件。适用范围为 Windows 桌面宿主、官方插件、托盘和安装向导。产品方向为轻量 Windows 工具，品牌限于图标、关于页及少量强调元素。界面提供简体中文与英文，默认跟随系统。

## 视觉规则

以下数值是本项目的设计起点。DIP 指 96 DPI 下的逻辑像素。系统字体大小、文本缩放和高对比度设置优先。

| 元素 | 规则 |
| --- | --- |
| 主题与表面 | 沿用「跟随系统／浅色／深色」。窗口、面板、正文、次要文字、分隔线、选中、焦点、危险各有独立颜色用途。自绘面的浅色参考值依次为底色 `#F7F7F7`、面板 `#FFFFFF`、正文 `#202020`、次要文字 `#505050`；深色对应 `#202020`、`#2B2B2B`、`#F5F5F5`、`#C6C6C6`。原生控件取兼容的系统颜色。 |
| 强调与状态 | 一个任务区最多一个实心强调按钮。强调色优先取系统强调色，按亮度选择前景并校验对比度。错误用图标和原因，选中用轮廓、勾或按下态，录制用圆点和「录制中」文字。高对比度模式采用系统前景、背景、选中和焦点色。 |
| 字体 | 使用 Windows 界面字体及系统中文回退。正文、按钮以 14 DIP 为起点，辅助信息 12 DIP，组标题 16 DIP 半粗，窗口内容标题 20 DIP 半粗。标题栏交给系统。数字尺寸始终按「宽 × 高 px」显示。 |
| 间距与层级 | 使用 4、8、12、16、24 DIP。图标和文字间隔 4，相邻控件 8，工具面板内边距 12，设置页内边距 16，设置分组间距 24。优先用空间和标题分组，分隔线仅用于区别不同职责。 |
| 控件与图标 | 常规按钮至少高 32 DIP，悬浮工具命中区至少 32 × 32 DIP，图形为 16 或 20 DIP；带文字的按钮左右各留 12 DIP。控件随实际字体增高。线性图标统一笔画、视重与对齐，避免依赖字体里的特殊符号。图标独立出现时提供可访问名称和键盘可见的提示。 |
| 边缘与层次 | 普通控件以 4 DIP 圆角、1 DIP 轮廓为参考。悬浮面板用清晰边缘贴合明暗截图。固定图、画中画沿用用户的圆角、阴影和透明度选择。框选边线在纯白、纯黑和复杂照片上均要清楚，并尊重用户自定义的线宽和颜色。 |
| 动效与反馈 | 截图、拖拽、缩放和精调直接跟手。普通悬停可用至多 120 ms 的短过渡。系统要求减少动画时直接切换。空闲界面按事件更新，状态文字只在有意义的变化时刷新或朗读。 |

## 布局与操作

- **空间。** 先测量当前语言的文字，再决定行宽、按钮宽度和溢出。布局按窗口所在显示器的 DPI 换算一次。取图、裁剪、拼接和导出的坐标继续使用原图物理像素。跨屏拖动后重新测量控件，截图像素保持逐点对应。
- **位置。** 框选工具栏优先在选区下方，其次上方；到屏幕边缘时沿当前显示器向内移动。长截图面板优先靠选区外侧，可用空间优先于固定停靠方向。交互控件避开任务栏、选区手柄和当前操作点。窗口重开时校正已拔除显示器的旧位置。
- **动作。** 执行按钮用动词，互斥选项显示当前值，持续工具显示按下态。按钮覆盖默认、悬停、按下、键盘焦点、禁用；可切换控件另有选中态。暂时不可用的核心动作占位并在附近解释前置条件，未安装插件的动作从入口移除。关闭窗口、取消任务、暂停自动滚动各用独立名称。
- **输入。** Tab 按阅读顺序移动，Shift+Tab 反向，方向键操作同组工具，Enter 或空格激活聚焦项。遇到文本编辑、快捷键录制及公开的可配置快捷键，以相应上下文为准。Esc 先退出当前弹层，再按任务语义处理。关闭菜单后焦点回到触发项。提示展示用户实际绑定的快捷键。
- **可访问性。** 普通正文对比度目标至少 4.5∶1，关键图形、边界和焦点标记至少 3∶1。焦点环建议 2 DIP。自绘按钮向 Windows 辅助技术提供名称、角色、状态和动作。悬停才显示的功能也提供键盘或上下文菜单入口。错误说明可被朗读并保持到用户能够处理。
- **反馈与恢复。** 可重试的错误留在原任务面板，说明发生了什么、哪些结果可用、下一步能做什么。后台更新和处理避免反复弹窗；已知进度给实际数值，未知进度给阶段名称。文件写入、复制等操作收到成功结果后才提示完成。
- **图像与焦点。** 预览可缩放以适配窗口。选框、工具条、阴影、状态标记等界面元素与输出像素分别绘制。实时采集检查系统排除窗口的结果，并验证现有重叠回退路径。面板更新避免激活窗口或截获目标应用的滚轮。

## 双语文案

- 设置入口为「语言 / Language」，选项为「跟随系统 / System」「简体中文」「English」。跟随 Windows 显示语言，中文环境使用简体中文，其余使用英文。手动选择持久保存。应用后刷新已打开的宿主界面，并保持焦点、选区和编辑草稿。进行中的插件任务若只支持启动时读取语言，则在该任务结束后生效。
- 使用稳定的动作 ID 绑定命令，宿主和各插件分别维护完整的中英文资源。整句翻译并使用具名占位，避免拼接半句。第三方动作缺少译名时保留作者提供的名称。官方界面的缺失译文在交付检查中列出。
- 同一动作在按钮、托盘、菜单、提示和设置中使用同一名称。例如「复制图片 / Copy image」「固定截图 / Pin image」「画中画 / Picture in picture」「长截图 / Scrolling capture」「暂停自动滚动 / Pause auto-scroll」。工具栏空间有限时可显示「复制 / Copy」，可访问名称仍说明对象。
- 错误示例：「这一步没有拼上。向回滚动一点后再试。」无新增内容和任务失败分别表述。技术信息、引擎名称和错误码放在详情中。通知中避免展示识别出的私密文字或截图缩略图。

## 各界面的约定

| 界面 | 布局、动作和关键状态 |
| --- | --- |
| 托盘与通知 | 以「截图」作为第一层入口。常用操作、设置、退出分组，退出放在末尾。通知服从用户开关，点击后回到相关任务。 |
| 框选、放大镜与标注 | 先完成选区，再展示适用动作；当前工具才展开颜色和线宽。尺寸标签跟随选区并避开手柄，放大镜避开指针。选区四边、角点和精调在明暗背景都可辨认。 |
| 共享编辑器 | 画布占主要空间；裁剪、切除行列、标注按操作对象分组，撤销与重做位置稳定。用轮廓或纹理标出待切除区域，预览与最终导出使用同一坐标映射。 |
| 固定截图与画中画 | 默认主要呈现图像，悬停或键盘聚焦时显示控制。固定图与实时画面的名称和状态可区分。拖动与缩放手柄优先于装饰；源窗口聚焦隐藏、右键动作与旧快捷键均可恢复和操作。 |
| 长截图 | 开始前提供「方向　竖向／横向」和主按钮「开始」。空间足够时两项并列，受选区尺寸限制的方向给出原因。开始后锁定方向并把滚动焦点交回来源。手动竖向上下、横向左右；自动竖向向下、横向向左或向右，运行中的方向提供「暂停」。暂停后仍能手动滚动。 |
| 长截图预览与导出 | 控制区、状态行、预览区位置稳定。首拼前提示「在选区内左右滚动」或「在选区内上下滚动」，保留开始后复制或编辑首帧的能力。首拼后显示真实成品的宽和高，横向看宽度增长，竖向看高度增长；折返经过已有内容时保持原尺寸。遇到无法对齐、区域变化或达到上限，显示对应恢复动作并保留已有结果。 |
| OCR 与翻译 | 图片、原文、译文分区；「复制原文」「复制译文」写明对象。识别中、无文字、缺少模型、失败和成功分别反馈。离线与在线引擎清楚标识，已有上传确认保留在实际发送之前。 |
| 录屏 | 准备、录制、暂停、结束处理、裁剪与导出使用不同状态。持续显示录制或暂停状态与时长，停止与暂停在位置和图形上可区分。录制控制避开采集内容，导出失败时说明可恢复的临时结果。 |
| 设置与插件管理 | 以现有常规、快捷键、插件、窗口效果、输入外观、关于为基础，使用稳定导航、分组标题、标签和说明。窄窗允许内容滚动，主要操作始终可达。待应用的设置给出修改状态，离开时能保留或放弃。插件安装、启用、正在运行和等待重启分别表达，卸载放入独立操作组。 |
| 安装与卸载向导 | 沿用系统向导和现有组件选择。简中与英文使用相同的插件名称与可选组件说明，安装错误提供明确的重试或退出路径。 |

## 工程边界

沿用 [Core 与插件契约](../architecture/core_plugin_contract.md)。宿主绘制宿主窗口和声明式动作，插件维护自己的任务状态及专用窗口。把间距、字号、颜色用途、文案键和控件状态作为共享规范；宿主内部优先复用现有布局与窗口视觉代码。主题和语言通过明确的偏好值传递。插件跨模块需要新信息时，先核对已发布接口，再决定是否增加可选、版本化的扩展，并验证旧宿主、旧插件的回退行为。

界面层把状态转换成文案和按钮可用性。拼接、OCR、翻译和录制引擎只提供事实，例如输出尺寸、是否已暂停及失败原因。为展示菜单而读取已登记的动作元数据即可；加载模型、执行采集和启动工作进程仍由用户动作触发。

## 交付与验收

**已确认的首批样板**为「框选 → 横向或竖向长截图 → 复制或编辑」。验收时走通两个方向和两个导出入口，并检查面板刷新后滚轮是否仍作用于来源窗口。主题与语言偏好的基础接线随首批样板提供。后续建议先迁移固定图与画中画，再处理设置、托盘、OCR、翻译、录屏和安装向导。

**已确认的工具栏布局**采用紧凑分组。复制和常用工具直接可点。宽度足够时按标注、撤销与重做、结果操作、已启用插件分组展示，长截图等已启用动作可一步启动。空间不足时优先保留复制、当前工具与「更多」，其余操作收入「更多」，沿用原分组和顺序。插件按登记的动作排序，同类动作适用同一收纳规则。

1. **建立基线。** 用无隐私的测试画面记录现有任务步骤、当前快捷键、焦点去向和典型窗口大小。记录空闲 CPU、工作集与首开耗时作为同机对照。对采集排除的浮层使用独立窗口测试或控件树核验。
2. **制作样板。** 先在代表性流程做中英、浅深色、正常与异常状态样板。每个状态标出主动作、退出方式、焦点去向和窄屏表现，再开始组件实现。
3. **分批应用。** 一个流程一次改完宿主入口、插件面板、文案与验证，再迁移其他窗口。优先使用原生按钮、列表、输入与菜单。需要自绘的截图工具条与图像覆盖层同步补齐键盘和辅助技术支持。
4. **回归验收。** 除视觉走查外，执行下表；照片和聊天内容用合成素材。保留失败场景、操作步骤及修复前后证据。

| 维度 | 最低验收样例 |
| --- | --- |
| 主题与语言 | 简中、英文分别覆盖浅色、深色；另测系统高对比度。打开设置切语言与主题，再重启验证持久化。现有用户的视觉设置和快捷键按原配置恢复。 |
| 密度与显示器 | 100%、125%、150%、200% DPI；额外放大系统文字；小工作区、负坐标副屏、跨屏拖动、断开副屏重开。逐项检查截字、重叠、失焦和不可点击按钮。 |
| 键盘与朗读 | 只用键盘完成工具选择、长截图开始、复制、编辑、取消；用 Windows 讲述人识别方向、当前工具、进度变化和错误动作。无悬停输入时也能调出对应操作。 |
| 插件与配置 | 无插件、单插件、多插件及超长动作名均能操作；禁用插件后入口及时更新，第三方语言回退和旧配置可用。冷启动和仅查看菜单时核对插件加载情况。 |
| 截图正确性 | 在同一合成画面执行上下、左右、折返、首次等待、拼接失败、面板重叠和到达上限。对照源图逐像素核验复制与编辑结果，检查固定侧栏、强对比边框、工具条和预览框。 |
| 性能与已有行为 | 同机比较改版前后首开、空闲与多悬浮窗的资源占用；空闲时无新增的持续重绘。运行受影响的宿主界面、输入、工具栏、长截图和对应插件测试，结合真实 Win32 窗口验证焦点与 DPI。 |

## 实现与验收记录

- 框选与标注工具栏提供键盘导航和辅助技术可读取的名称、状态与操作。固定图标注时会临时扩大过小的窗口，用户在编辑中移动或调整过窗口时保留其新位置和大小。设置在窄窗中可滚动，应用按钮保留在底部。
- 已校验长截图拼接像素、OCR 和翻译的真实离线流程、录屏导出、旧插件入口、配置持久化和辅助技术接口。布局测试覆盖负坐标工作区及 100%、125%、150%、200% 的数学布局。双语安装器编译通过，三个官方插件通过隔离用户目录的安装命令验证。
- 同机隔离配置下，改版前后各启动 5 次。Windows 消息循环等待中位数为 48.1 → 51.9 ms，空闲工作集为 12.61 → 12.71 MiB。每次 1.25 秒采样中均未观察到增加的进程 CPU 时间。
- 真实桌面验收还需检查源窗口前台焦点、不同 DPI 显示器之间的拖动、高对比度和 Windows 讲述人的朗读效果。屏幕像素验收需要测试窗口在交互桌面可见。
