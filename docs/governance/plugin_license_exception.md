## 适用范围

- 明确附带例外的 Nskry 自有 Core（src/）、公开 sdk/nskry_plugin.h 和 Core 构建脚本。
- 仅经公开、已文档化插件接口结合的独立开源插件，可以选自己的开源许可证，无须仅因结合改用 GPL。
- “开源”依照 OSI Open Source Definition 1.9；不是只有源码可见，也不限定只能采用 GPL。
- 公开 SDK 的声明、常量、宏、内联和示例可必要复制/适配；源码分发保留适用声明。
- Core 对应源码义务仍保留，插件自己的源码交付按自己的许可证；不能借例外藏起修改后的 Core。
- 本次范围为独立开源插件；闭源/非开源插件不在此例外范围内。扩大范围需要另行授权和修订。

## 不适用范围

复制/改造 Core 实现、访问私有内部接口，不因挪进 DLL 或 worker 自动成为独立插件。
第三方代码、库、模型、资产、官方插件本身不被此条款重新许可；各自原声明保留。
官方 OCR/Scroll 仍按其 GPL 声明发布，包内附宿主例外不等于其实现变成任意许可。
例外不提供商标、官方身份、保证，不允许冒充来源；不加禁止销售或强制水印。

下游可按 GPL 第 7 节移除附加许可，新增代码的权利人未必授予它；插件作者必须核对实际 fork 声明。
旧包或旧版本没有此声明时不能假定追溯获得例外。未承诺当前所有依赖组合都自动合规。
