# 官方与第三方插件政策

生效范围：当前 Nskry 插件管理说明，2026-10-08。以下不改变 GPL 授予的权利；
责任条款仅在适用法律允许范围内适用，不排除不能依法排除的责任或法定消费者权利。

## 身份定义

官方插件由 Nskry 维护者开发，或由维护者明确认证收编的个人/团队开发。
认证应有 ID、发布者、维护责任、版本及撤销记录，不能由 manifest 自称“官方”获得。
第三方插件由独立开发者/团队自行发布；收录链接、能够安装、HTTPS、SHA-256、
可用的更新地址均不等于官方认证，也不保证无恶意代码、错误或漏洞。

当前 `source_type=official` 只记录安装来源；没有密码学身份认证。
官方入口尚未上线、未配置时仅提示不可用，不联网，也不伪造认证标记。
即使未来通过发布者认证，也不意味着每个版本免除测试或具备绝对安全保证。

## 安装风险与用户选择

第三方插件的许可由其开发者选择，Nskry 不要求其统一采用某个开源许可证。
作者仍须遵守自己使用的代码、模型和依赖许可；宿主的
[独立开源插件例外 1.0](../../PLUGIN_EXCEPTION) 允许通过公开 SDK 结合的独立开源插件自选开源许可，
不覆盖闭源或复制 Core 实现的插件。详见 [许可范围](../governance/plugin_license_exception.md)。
允许独立前置插件，但必须明确职责、版本和安装范围，不能用一个小服务强制捆绑无关大功能。
当前 API 2 不具备前置解析/服务协商；此政策是后续支持方向，不宣称现版本可安装有前置的插件包。

原生 DLL 与 Nskry 在同一进程、拥有同一用户权限，不是沙箱。
它可能访问截图、文件、剪贴板、网络，或影响程序稳定性；关闭通知不等于禁止联网。
安装前用户应检查发布者、源码、许可、隐私政策、更新源及真实功能；默认取消安装确认。
用户可禁用或卸载；已加载的 DLL、更新与卸载通过重启完成，禁用不是即时杀死恶意代码的安全边界。

插件作者/发布者对自己的功能、内容、更新、依赖授权、隐私说明及支持负责。
在适用法律允许范围内，Nskry 维护者不为独立第三方插件提供保证或承诺补偿其损害。
本说明不是免除维护者自身依法承担责任的万能条款，不能取代个别法域的正式法律审核。
Nskry 代码的无担保说明以 GPL 第 15、16 节及适用法律为准。

## 更新与隐私

仅在用户点击 Check for updates 时，读取官方 catalog 或该插件声明的发布者 feed。
官方记录不读取插件自身 update.url；第三方 feed 不能更新别人的 ID 或官方记录。
网络请求会向所访问的网站暴露通常的连接信息（例如 IP），不上传截图/OCR 文字或完整插件清单。
访问官网浏览下载入口会打开用户浏览器，并受该网站的隐私政策约束。
下载需用户确认，验证 HTTPS、hash、package ID/version/兼容性，重启后应用。
无更新源或网络失败必须提示“未检查”，不等同于确认最新。

## 投诉与认证撤销规划

官网上线前不设置虚构投诉邮箱。官网应提供安全/冒充/许可违规举报入口，
收集版本、来源 URL、包 hash、错误证据和可复现步骤，避免提交敏感截图。
维护者核实后可下架/撤销官方认证并发布风险公告；吊销不自动删除用户文件或私自运行远程代码。
正式官方目录须具备签名验证、签名密钥轮换/吊销和发布者认证记录，不能仅靠页面文字。
